# XLinUI · 本地开发插件

个人现代界面插件，命令 `/xlinui`。当前已针对上游 Dalamud **15.0.3.6 / API 15** 编译出 DLL；尚未在国服 soil 或游戏内执行。云端不能直接安装到你的电脑，也不能访问你的游戏进程。API Level 相同不保证 soil 分支的全部接口一致。

## 下载

- [XLinUI 插件包](https://github.com/HanaSi0/others/raw/refs/heads/main/artifacts/XLinUI-0.1.0-api15.zip)
- [XLinUI 源码包](https://github.com/HanaSi0/others/raw/refs/heads/main/artifacts/XLinUI-0.1.0-source.zip)

## 本地加载

1. 下载 `artifacts/XLinUI-0.1.0-api15.zip` 并解压到固定目录，例如 `D:\FF14Plugins\XLinUI`。不要在 ZIP 内直接加载。
2. 游戏中打开 Dalamud 设置（通常为 `/xlsettings`），找到开发插件路径 / **Dev Plugin Locations**，添加解压后的 `XLinUI.dll` 完整路径；保存设置。不同 soil 版本的菜单可能不同。
3. 打开 `/xlplugins`，在开发插件列表中启用 **XLinUI**。若未列出，刷新开发插件列表。插件入口类为 `XLinUI.Plugin`，清单 API Level 为 15。
4. 输入 `/xlinui` 打开设置。聊天开始收集加载后的消息。`/xlinui off` 关闭新面板，`/xlinui on` 重新开启。
5. **游戏交互默认关闭**。初次检查面板和聊天接收后，在设置中开启它，才能使用顶部入口、发送聊天、读取/点击热键栏。原版界面始终保留。

若提示加载失败，请在 `/xllog` 查看并提供 XLinUI 的错误片段，不要提供账号、密钥或完整聊天日志。若你的 soil 暴露不同的接口，需要按实际程序集重新编译或适配源码。

## 按你的 soil 本地编译

需要 .NET 10 SDK。下载源码包解压，在 PowerShell 中运行：

```powershell
.\Build-Local.ps1 -DalamudPath 'D:\实际路径\包含Dalamud.dll的目录'
```

此路径应来自 soil 实际安装，不要套用普通 XIVLauncher 默认路径，也不要将上游程序集复制到 soil 中。脚本通过 `DALAMUD_HOME` 使用你提供的程序集，按锁文件恢复依赖，然后编译。生成的开发 DLL 位于 `bin\Release\XLinUI.dll`。

## 已实现

- 模块总开关和独立开关、顶部入口（角色/背包/任务/地图/传送/好友）。
- 分类聊天：改名、增删、多个游戏频道过滤、未读计数、跟随消息。最多 1000 条纯文本记录，不保存到磁盘，退出角色后清空。
- 手动发送说话/小队/部队/喊话/呼喊；输入框不执行任意斜杠命令。游戏负责频道权限及发送结果。保守限制为单行、最多 450 UTF-8 字节。
- 方角技能栏：镜像指定的原版热键栏 1–10，显示 12 个槽位、游戏图标和冷却秒数，鼠标点击调用对应槽位。不会修改槽位、宏或快捷键绑定，键盘操作继续走游戏原版绑定。
- 技能栏固定直角。其他插件窗口可切圆角/直角，背景透明度、半透明玻璃风格、色调和技能格尺寸可调。窗口可移动，设置持久保存于 Dalamud 插件配置。

## 本版限制

- **没有实际背景模糊**：ImGui 半透明背景不是浏览器的 backdrop-filter。本版提供玻璃风格和透明度；真实模糊需要额外渲染实现。
- 不修改原版窗口边框，不自动隐藏原版聊天/热键栏，也不替换全部原版 UI。
- 新聊天为纯文本；物品、地图、玩家链接仍在原版聊天操作，暂不支持从新面板指定私信收件人。发送分类与接收分类相互独立。
- 热键栏镜像不具备拖拽编辑、完整技能高亮或所有原版状态效果。
- 游戏交互调用依赖 Dalamud 提供的 FFXIVClientStructs 绑定。托管异常会关闭游戏交互，但这不能保证拦截原生崩溃；soil 兼容性需要实际版本验证。
